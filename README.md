# 💰 Gestione Finanza Personale di Coppia

Applicazione web per la gestione della finanza personale e degli investimenti per una coppia.

## 🌟 Funzionalità

### 📊 Schede Personali (Partner 1 e Partner 2)
- Aggiungi stipendio mensile per ogni partner
- Registra spese personali con descrizione, importo e data
- Visualizza il totale degli stipendi, delle spese e il saldo personale
- Storico completo di tutte le transazioni

### 🤝 Spese Condivise
- Aggiungi spese condivise (es: affitto, bollette)
- Indica chi ha pagato la spesa
- Calcolo automatico di chi deve dare soldi all'altro
- Sistema di bilanciamento equo (50/50)
- Visualizzazione chiara del debito/credito tra i partner

### 📈 Investimenti
- Traccia allocazioni mensili per categoria (ETF, PAC, Oro, Azioni, Obbligazioni, Altro)
- Visualizza il totale allocato
- Diversificazione per categoria con percentuali
- Storico completo degli investimenti

### 💹 Rendimenti di Mercato
- Visualizzazione dei rendimenti di mercato (Oro, S&P 500, MSCI World, Euro Stoxx 50, ecc.)
- Dati dimostrativi con note per l'integrazione di API reali (Alpha Vantage, Yahoo Finance, Metals API)

### 💾 Persistenza Dati
- Tutti i dati vengono salvati automaticamente nel browser (localStorage)
- I dati rimangono disponibili anche dopo la chiusura del browser

## 🚀 Come Usare

1. Apri il file `index.html` in un browser web moderno
2. Naviga tra le diverse schede usando i pulsanti in alto
3. Aggiungi stipendi, spese e investimenti utilizzando i form disponibili
4. Visualizza i riepiloghi e gli storici in tempo reale

## 🛠️ Tecnologie Utilizzate

- **HTML5** - Struttura dell'applicazione
- **CSS3** - Styling moderno e responsive
- **JavaScript (Vanilla)** - Logica dell'applicazione
- **LocalStorage API** - Persistenza dei dati

## 📱 Responsive Design

L'applicazione è completamente responsive e funziona su:
- 💻 Desktop
- 📱 Tablet
- 📱 Smartphone

## 🔧 Integrazione API Future

Per integrare dati reali di mercato, è possibile utilizzare:
- **Alpha Vantage** - Per ETF e azioni
- **Metals API** - Per oro e metalli preziosi
- **Yahoo Finance API** - Per dati finanziari generali
